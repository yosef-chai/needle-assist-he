# Needle Assist - עוזר קולי בעברית ל‑Home Assistant

[![validate](https://github.com/Yosef-Chai/needle-assist-he/actions/workflows/validate.yml/badge.svg)](https://github.com/Yosef-Chai/needle-assist-he/actions/workflows/validate.yml)
[![hacs](https://img.shields.io/badge/HACS-custom-41BDF5.svg)](https://hacs.xyz)

שליטה בבית החכם בעברית - מדוברת, לא רק תקנית - **בלי ענן, בלי מנוי, בלי ששום דבר יוצא מהבית**.

המודל, המנוע וההיגיון כולם רצים על אותה מכונה שמריצה את Home Assistant. אין קריאת רשת בזמן שיחה. הדבר היחיד שיורד מהאינטרנט הוא ספריית המנוע (כ‑14MB), פעם אחת, בהתקנה הראשונה.

```
"תדליק את האור בסלון"                          → light.turn_on
"סגור את התריסים בחדר של הילדים"                → cover.close_cover
"תכבה את האור בסלון וסגור את התריסים"           → שתי פעולות במשפט אחד
"שים את המזגן על 23 בחדר שינה"                  → climate.set_temperature
"מה המצב של המזגן במטבח"                        → get_state   ← לא יפעיל כלום
"תפעיל את מצב לילה"                             → scene.turn_on
"אל תדליק את האור"                              → סירוב
"מה מזג האוויר בפריז"                           → סירוב
```

---

## מה זה עושה

- **42 כלים**, כולם שירותים אמיתיים של Home Assistant - תאורה, תריסים, מיזוג, מנעולים, מדיה, מוזיקה, שקעים, שואב, מצלמות, סצנות, סקריפטים, אוטומציות, טיימרים, התראות ושאילתות מצב.
- **מזהה את החדרים של הבית שלך**, לא רשימה קבועה מראש. אם יש לך "הול", "חדר כביסה" או "פינת קפה" - הם יעבדו, כולל בכינויים שהגדרת ב‑Home Assistant.
- **מבין עברית מדוברת**: תחיליות (בסלון, ולמטבח, שבמקלחת), אותיות סופיות במקום הלא נכון, מילים דבוקות מזיהוי דיבור, וטעויות הקלדה.
- **כמה פעולות במשפט אחד.** "תכבה את האור במטבח וסגור את התריסים בחדר שינה" הן שתי פקודות, ושתיהן מבוצעות.
- **מנגן מוזיקה בשם** דרך [Music Assistant](https://www.music-assistant.io/). שם השיר נקרא מהמשפט, לא מומצא על ידי המודל. בלי Music Assistant מותקן זה פשוט ממשיך נגינה על הרמקול שבחדר.
- **שאלה לא יכולה להפעיל כלום.** "מה המצב של האור במטבח" מחזיר תשובה, לא מדליק אור.
- **הפועל בעברית קובע את הכיוון.** "נעל את הדלת" נועל, "תנמיך את המזגן" מוריד - והמילים גוברות על המודל, כי היפוך כיוון הוא הטעות הגרועה ביותר שעוזר בית יכול לעשות.
- **מסרב למה שלא קשור לבית**, ומסרב לפקודות שליליות ("אל תדליק").
- עונה בעברית.

### הגדרה

**הגדרות ← מכשירים ושירותים ← הוספת שילוב ← Needle Assist (Hebrew) ← המשך.**

אין מה למלא - המודל המכוונן מגיע יחד עם האינטגרציה. בהתקנה הראשונה יורדת ספריית המנוע (כ‑14MB) ונשמרת תחת `/config`, כך שהיא שורדת עדכוני ליבה.

לסיום: **הגדרות ← עוזרים קוליים**, ובחר את Needle Assist כסוכן השיחה.

> **שייך חדר לכל ישות.** פקודה כמו "תדליק את האור בסלון" מגיעה לישויות דרך רישום האזורים של Home Assistant. ישות בלי אזור לא תימצא באף פקודת חדר. זו התנהגות של Home Assistant עצמו, אבל היא מפתיעה.

## אפשרויות

**הגדרות ← מכשירים ושירותים ← Needle Assist ← הגדרות**

| הגדרה | ברירת מחדל | מה זה |
|---|---|---|
| **רמקול למוזיקה** | ריק | על איזה רמקול של Music Assistant לנגן כשלא נאמר חדר במפורש |
| **מקסימום טוקנים לאמירה** | 192 | קריאת כלי היא כ‑25 טוקנים, השאר נועד למשפטים עם כמה פקודות. העלאה אינה משפרת את איכות התשובה |

**נתיב למודל משלך:** `⋮ ← הגדרה מחדש`. שדה ריק פירושו המודל שמגיע עם האינטגרציה, וזו גם הדרך לחזור אליו.

## מה אפשר להפעיל

האינטגרציה לא מביאה מכשירים משלה. היא מפעילה את מה שכבר מותקן אצלך, דרך השירותים הרגילים של Home Assistant:

| תחום | מה אפשר לומר |
|---|---|
| `light` | להדליק, לכבות, בהירות, אחוזים, למעלה ולמטה, צבע בשם |
| `switch` | להדליק, לכבות |
| `climate` | להדליק, לכבות, טמפרטורה מוחלטת, מצב, עוצמת מאוורר |
| `cover` | לפתוח, לסגור, לעצור, אחוז פתיחה |
| `lock` | לנעול, לשחרר |
| `media_player` | לנגן, להשהות, ווליום, השתקה, שיר הבא, מקור |
| `music_assistant` | לנגן אלבום/פלייליסט/רדיו/אמן בשם |
| `vacuum` | להתחיל, לעצור, לחזור לתחנה, עוצמת שאיבה |
| `fan` | להדליק, לכבות, סיבוב |
| `camera` | לצלם תמונה |
| `scene` / `script` / `automation` | להפעיל לפי שם |
| `timer` | להפעיל, לבטל |
| `input_boolean` / `input_number` | להדליק, לכבות, לקבוע ערך |
| `notify` | לשלוח הודעה |
| שאלות | מצב של ישות, טמפרטורה, מזג אוויר |

**מה שלא נתמך, בכוונה:** כל שירות שלא קיים ב‑Home Assistant. הדקדוק של המנוע נבנה מרשימת הכלים המוצהרת, ולכן קריאה לשירות שלא הוצהר היא בלתי אפשרית לייצוג. המודל לא *יכול* להמציא שירות.

## דוגמאות

להריץ משפט מתוך אוטומציה - למשל כפתור פיזי שאומר אותו:

```yaml
action:
  - action: conversation.process
    data:
      agent_id: conversation.needle_assist
      text: "תכבה את כל האורות ותנעל את הדלת"
```

לשאול משהו ולהשתמש בתשובה, בלי להפעיל כלום:

```yaml
action:
  - action: conversation.process
    data:
      agent_id: conversation.needle_assist
      text: "מה המצב של האור במטבח"
    response_variable: answer
  - action: notify.persistent_notification
    data:
      message: "{{ answer.response.speech.plain.speech }}"
```

## איך זה מתעדכן

אין כאן סקרים ואין רענון תקופתי. מצב הבית נקרא **ברגע שמדברים אליה**, ולא לפני כן:

- **חדרים וישויות** נקראים מרישום האזורים ומרישום הישויות בכל אמירה. חדר שהוספת או כינוי ששינית תופסים מיד, כי האינדקס נבנה מחדש באירוע השינוי.
- **מצב מכשירים** נקרא מ‑`hass.states` באותו רגע, לצורך שאלות ולצורך פקודות יחסיות ("תעלה קצת" הוא המצב הנוכחי ועוד).
- **המודל** נטען פעם אחת, בהפעלת האינטגרציה. שינוי הגדרות טוען אותו מחדש.
- **ספריית המנוע** יורדת פעם אחת לכל גרסת מנוע, בהתקנה הראשונה. אחר כך אין שום קריאת רשת.

## מגבלות ידועות

הרשימה כתובה במלואה בכוונה. עדיף לדעת מראש.

- **כל פקודה במשפט עולה זמן.** המשפט נחתך לפי פקודות והמודל רץ פעם אחת לכל אחת, ולכן יש תקרה של ארבע פקודות במשפט.
- **חיתוך המשפט מסתמך על פועל.** "תדליק את האור בסלון, ובמטבח תסגור" - פועל שבא אחרי החדר במקום לפניו - לא תמיד ייחתך נכון. הניסוח הרגיל, פועל בתחילת כל פקודה, כן.
- **מוזיקה בשם דורשת Music Assistant.** בלעדיו בקשה לנגן משהו רק ממשיכה נגינה על הרמקול שבחדר, כי אין ספרייה לחפש בה.
- **שאלה בלי מילת שאלה לא תמיד מזוהה ככזו.** "התריס בסלון פתוח" בלי סימן שאלה עמום גם בעברית. היא לא תפעיל כלום בטעות, אבל היא עלולה לא לענות.
- **טקסט חופשי בארגומנט נלקח מהמשפט, לא מהמודל.** עברית מגיעה לארגומנט של כלי כרצף בריחה של שישה תווים לאות, והמודל טועה בהם. גוף ההתראה נחתך מהמשפט; אם אי אפשר לחתוך אותו, ההתראה לא נשלחת במקום לשלוח ג'יבריש.
- **ישות בלי אזור לא נגישה בפקודת חדר.** זו התנהגות של Home Assistant, לא באג כאן, אבל היא מפתיעה.
- **עברית בלבד.** האינטגרציה מצהירה `he` ולא `MATCH_ALL`, כדי ש‑Assist לא ינתב אליה אנגלית.

## הסרה

**הגדרות ← מכשירים ושירותים ← Needle Assist ← ⋮ ← מחק.**

זה מספיק. המחיקה לוקחת איתה **את כל מה שהאינטגרציה יצרה**:

- את המכשיר ואת ישות השיחה שלה, מתוך הרישומים;
- את ספריית המנוע שירדה, `/config/needle_assist_engine/` - כ‑13MB לכל גרסת מנוע;
- את דוח התיקון שהיא אולי פתחה, כדי שלא יישאר בלוח התיקונים אחרי שהיא כבר לא מותקנת.

אחר כך אפשר להסיר את המאגר מ‑HACS, וזה מוחק את `custom_components/needle_assist/` על המודל שבתוכו.

> **הסדר חשוב.** Home Assistant יכול לנקות רק בזמן שהקוד עוד נמצא על הדיסק, ולכן צריך למחוק קודם את השילוב ורק אז להסיר מ‑HACS. בסדר ההפוך הקוד נעלם ראשון, אין למי לפנות, וספריית המנוע נשארת - במקרה כזה אפשר למחוק את התיקייה `needle_assist_engine` שתחת `/config` ביד.

קובץ `.cact` שהעתקת בעצמך למקום כלשהו הוא שלך, והאינטגרציה לא נוגעת בו.

## פרטיות

- אין שום קריאת רשת בזמן שיחה. המשפטים שלך לא יוצאים מהמכונה.
- הדבר היחיד שיורד מהאינטרנט הוא ספריית המנוע, פעם אחת, בהתקנה הראשונה, מ‑Hugging Face. אפשר גם להעתיק אותה ידנית ולהישאר מנותק לגמרי.
- אין טלמטריה, אין דיווח שימוש, אין מפתחות API.

## בעיות

**הגדרות ← מכשירים ושירותים ← Needle Assist ← ⋮ ← הורדת אבחון** מייצר דוח עם מה שהאינטגרציה רואה: איזה מודל נטען, אילו חדרים היא זיהתה ובאילו מילים אפשר לפנות לכל אחד, כמה ישויות ברות‑פנייה, ומצב השערים. הדוח לא מכיל אף משפט שאמרת. זה המקום להתחיל.

| מה קורה | למה, בדרך כלל |
|---|---|
| "לא הבנתי" על כל דבר | ה‑pipeline לא מוגדר לעברית, או שנבחר עוזר שיחה אחר |
| פקודה תקינה לא מוצאת כלום | לישות אין אזור |
| חדר מסוים אף פעם לא נתפס | השם שאתם אומרים אינו שם האזור. להוסיף אותו ככינוי לאזור; באבחון יש `reachable_by` לכל חדר |
| "תנגן X" רק ממשיך נגינה | אין Music Assistant מותקן, או שהרמקול שלו אינו באזור שנאמר |
| האינטגרציה לא עולה אחרי עדכון | דוח תיקון בשם "לא מוצא את קובץ המודל". `⋮ ← הגדרה מחדש`, ולרוקן את השדה |
| הפעלה ראשונה נכשלת בלי רשת | ספריית המנוע יורדת פעם אחת. הודעת השגיאה כוללת את הכתובת ואת הנתיב, להתקנה ידנית |
| תשובה איטית מאוד | כל פקודה במשפט היא ריצה נפרדת של המודל. משפט עם ארבע פקודות לוקח פי ארבעה |

## In English

**Needle Assist** is a fully local Hebrew conversation agent for Home Assistant. The model, the inference engine and all of the logic run on the machine running Home Assistant; there is no network call during a conversation, no cloud service and no API key. The only download is the engine's native library, once, at first setup.

It exposes **42 tools**, every one a real Home Assistant service, and it understands colloquial Hebrew rather than only the written register - prefix particles, misplaced final letters, words glued together by speech-to-text. Several orders in one sentence are split and executed in turn. A question cannot actuate anything.

Measured on all **2,379 held-out rows**: **76.4%** correct tool, **61.7%** tool and every argument, **75.0%** correct refusal of off-topic input. The same weights without the deterministic layer around them score **51.1% / 28.9% / 0.5%** - nearly half of what this system gets right, it gets right outside the model. 237 tests, 95% coverage, `mypy --strict` clean.

Requires Home Assistant 2024.11+, x86_64 or aarch64, ~40MB of disk, no GPU. Install through HACS as a custom repository, category *Integration*, then add it under **Settings → Devices & services** and pick it as your conversation agent under **Settings → Voice assistants**. Removing the integration removes everything it created, including the downloaded engine.

Code is MIT; the bundled model is a fine-tuned derivative of [Cactus-Compute/needle2](https://huggingface.co/Cactus-Compute/needle2) under Apache-2.0. See [`NOTICE`](NOTICE).
